# L2: Context

The instructions and information available to a model on each inference. Compare what is selected, compressed or removed, and how the agent receives it.

## Primary tools

| Tool | Purpose | Artifact | Verification |
|---|---|---|---|
| [AGENTS.md](../../data/tools/agentsmd__agents.md.json) | A shared file convention for placing agent-facing instructions in a repository. A convention, not a tool. | convention file (persistent) | ok |
| [CodeGraph](../../data/tools/colbymchenry__codegraph.json) | Indexes a repository into a code graph that stays in sync with the files, so an agent asks the graph instead of reading its way there. Local, and reachable over MCP from nine harnesses. | pre-indexed code graph (persistent) | ok |
| [.NET Agent Skills](../../data/tools/dotnet__skills.json) | Microsoft's official curated collection of Agent Skills and custom agents for .NET/C# development, spanning builds, tests, upgrades, diagnostics, and AI integration, installable across Claude Code, Copilot CLI, Cursor, Codex CLI, and VS Code. | skill/plugin files installed into the harness's project or plugin marketplace (persistent) | ok |
| [snip](../../data/tools/edouard-claude__snip.json) | CLI proxy whose filters are written declaratively in YAML. Prioritises explicit configuration over defaults. | filter definitions (persistent) | ok |
| [Framelink Figma MCP](../../data/tools/glips__figma-context-mcp.json) | Serves Figma layout data to a coding agent over MCP, simplifying the API response first so the design arrives as context rather than as a screenshot. | simplified layout data passed into context (ephemeral) | ok |
| [Headroom](../../data/tools/headroomlabs-ai__headroom.json) | Compresses tool output, logs, files and RAG chunks before they reach the model. | none (compression path) | ok |
| [Skills for Real Engineers](../../data/tools/mattpocock__skills.json) | A set of engineering and productivity skills installed into a project as editable source files, covering TDD, spec and ticket generation, and architectural review. | skill files, CONTEXT.md and ADRs written into the project (persistent) | ok |
| [Serena](../../data/tools/oraios__serena.json) | Semantic code search backed by a language server, served over MCP. A tool for avoiding whole-repository injection. | none (search path) | ok |
| [RTK (Rust Token Killer)](../../data/tools/rtk-ai__rtk.json) | CLI proxy that compresses shell command output before it reaches the model, intervening transparently through hooks. | none (output compression path) | ok |
| [Context7](../../data/tools/upstash__context7.json) | Injects current library documentation over MCP, reducing errors caused by stale knowledge. | none (retrieval path) | ok |
| [skills CLI](../../data/tools/vercel-labs__skills.json) | A command line for the open skills ecosystem: install a skill into a project, or generate its prompt and run an agent with it without installing anything. | skill files written into the project, or a temporary prompt (persistent or ephemeral) | ok |
| [Agentic Plugin Marketplace](../../data/tools/wshobson__agents.json) | A marketplace of agent definitions, skills and commands maintained as one Markdown source and rendered natively onto five harnesses. | plugin, agent and skill definitions in Markdown (persistent) | ok |
| [Repomix](../../data/tools/yamadashy__repomix.json) | Packs an entire repository into one file shaped for a model. | packed context (ephemeral) | ok |
| [LeanCTX](../../data/tools/yvgude__lean-ctx.json) | Sits between an existing agent and the model: caches and compresses file reads, command output and each request before they arrive, and carries session memory and a cost ledger across chats. | Session memory, a BM25-indexed artifact registry, and a savings ledger with receipts, held in the tool local store (persistent). The compressed request and the shaped command output are a path, not an artifact. | ok |
| [Claude Context](../../data/tools/zilliztech__claude-context.json) | Semantic code search served over MCP: the codebase goes into a vector index once, and the agent retrieves the relevant parts instead of being handed directories. | vector index of the codebase (persistent) | ok |
