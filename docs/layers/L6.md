# L6: Loop

Repeated work, feedback and stopping conditions. Compare iteration limits, external verification, recovery and the conditions that terminate a run.

## Primary tools

| Tool | Purpose | Artifact | Verification |
|---|---|---|---|
| [DeerFlow](../../data/tools/bytedance__deer-flow.json) | A harness built for tasks measured in hours rather than turns: subagents, sandboxes, memory and skills coordinated behind one long-horizon loop. | session memory, sandbox state and skill definitions (persistent) | ok |
| [Loop Engineering](../../data/tools/cobusgreyling__loop-engineering.json) | A pattern library for operating agents around a codebase: loops that discover work, hand it to an agent, verify the result and persist state, with an audit and a cost tool beside them. | loop definitions and STATE.md (persistent) | ok |
| [Ralph for Claude Code](../../data/tools/frankbria__ralph-claude-code.json) | An implementation of the Ralph loop for Claude Code. Runs autonomous iteration with a dual-condition exit gate and rate limiting, which is the cap the pattern itself leaves to the operator. | loop configuration and prompt files (persistent) | ok |
| [Ralph Loop (pattern)](../../data/tools/ghuntley.com__ralph.json) | Stateless repetition pattern: retry the same task until an external check passes. | loop script (hand-written) | ok |
| [Superpowers](../../data/tools/obra__superpowers.json) | A set of skills paired with a methodology: design, plan, then TDD through subagents. | skill definitions (persistent) | ok |
| [Open Ralph Wiggum](../../data/tools/th0rgal__open-ralph-wiggum.json) | One command puts any of six coding agents into a Ralph loop, switching harness with a flag. The loop is the product; the agent underneath is interchangeable. | prompt file and loop state (persistent) | ok |
