# L7: Coordination

Division of work among agents. Compare coordination, handoffs, shared state, verification and the authority given to each participant.

## Primary tools

| Tool | Purpose | Artifact | Verification |
|---|---|---|---|
| [AG-UI](../../data/tools/ag-ui-protocol__ag-ui.json) | An event-based protocol for the connection between an agent and the interface a person is looking at, with reference integrations for several agent frameworks. | protocol implementations and integrations (persistent) | ok |
| [CLI Agent Orchestrator (CAO)](../../data/tools/awslabs__cli-agent-orchestrator.json) | Coordinates multiple AI coding CLIs (Claude Code, Codex, Kiro, and nine others) as a supervisor delegating to parallel or sequential workers, each running as a full CLI process in an isolated tmux session. | tmux sessions and a workflow/event journal (ephemeral by default; opt-in self-learning can promote lessons into agent profile files) | ok |
| [CrewAI](../../data/tools/crewaiinc__crewai.json) | Forms teams of role-bearing agents and divides tasks among them. | agent and task definitions | ok |
| [container-use](../../data/tools/dagger__container-use.json) | Gives each agent a container and a separate branch, so they run in parallel. | isolated environments | ok |
| [Swarms](../../data/tools/kyegomez__swarms.json) | Prebuilt multi-agent architectures, sequential, concurrent and hierarchical, offered as ready shapes rather than as primitives to assemble. | swarm and agent definitions (persistent) | ok |
| [Nimbalyst](../../data/tools/nimbalyst__nimbalyst.json) | Open-source visual desktop workspace for running Codex, Claude Code, OpenCode and Copilot in parallel git worktrees, editing their work in WYSIWYG markdown/mockup/diagram editors, and reviewing diffs before they land. Formerly Stravu Crystal, renamed 2026. | on-disk markdown, mockup, diagram and data-model files plus a local session/task database (persistent) | ok |
| [Ruflo](../../data/tools/ruvnet__ruflo.json) | Orchestration harness that coordinates many agents in hierarchical, mesh or adaptive swarms, with consensus and a persistent vector memory. | swarm topology and agent memory (persistent) | ok |
| [Orca](../../data/tools/stablyai__orca.json) | Runs several coding agents side by side, each in its own git worktree, and puts the comparison of their results in front of a person before anything is merged. | parallel git worktrees and their diffs (persistent) | ok |
