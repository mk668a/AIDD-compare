# L4: Specification

The intended change expressed before implementation. Compare specification units, authority, lifecycle and the artifacts handed to an agent or reviewer.

## Primary tools

| Tool | Purpose | Artifact | Verification |
|---|---|---|---|
| [drawio-skill](../../data/tools/agents365-ai__drawio-skill.json) | Turns text and real system sources into maintainable .drawio architecture models, syncs them incrementally without discarding manual layout, and enforces architecture contracts as a test in CI. | a .drawio model with a separate diagram intermediate representation (persistent) | ok |
| [AI-DLC Workflows](../../data/tools/awslabs__aidlc-workflows.json) | Adaptive workflow steering rules implementing the AI-Driven Life Cycle. 5 phases and 33 stages driven by a 14-agent roster, rendered onto seven harnesses from one harness-neutral core. | aidlc/ workspace, harness-specific config and AGENTS.md (persistent) | ok |
| [BMAD-METHOD](../../data/tools/bmad-code-org__bmad-method.json) | Heavyweight framework running planning through implementation across many role-separated agents. | documents per stage (persistent) | ok |
| [OpenSpec](../../data/tools/fission-ai__openspec.json) | Describes changes as ADDED / MODIFIED / REMOVED deltas, so the spec survives and grows. | delta specs (persistent) | ok |
| [GitHub Spec-Kit](../../data/tools/github__spec-kit.json) | CLI running spec, plan, tasks and implementation as four stages. A constitution pins the constraints. | spec set (leans ephemeral) | ok |
| [DESIGN.md](../../data/tools/google-labs-code__design-md.json) | A file format for describing a visual identity to a coding agent: machine-readable tokens in front matter, and the reasoning behind them in prose. Ships a validator that checks token references and WCAG contrast. | a DESIGN.md file per project (persistent) | ok |
| [cc-sdd](../../data/tools/gotalab__cc-sdd.json) | Four phases: requirements, design, tasks, implementation, with a human approval gate between each. Multilingual, including Japanese. | phase documents (persistent) | ok |
| [MoAI-ADK](../../data/tools/modu-ai__moai-adk.json) | CLI wrapping a coding agent. Spec-first Plan, Run, Sync with a TDD gate between. | SPEC plus tests (persistent) | ok |
| [GSD Core](../../data/tools/open-gsd__gsd-core.json) | Meta-prompt driven SDD run as a five-step phase loop: discuss, plan, execute, verify, ship. Heavy work runs in fresh-context subagents to keep the main session lean. | phase definitions and prompts (persistent) | check |
| [Planning with Files](../../data/tools/othmanadi__planning-with-files.json) | Keeps the plan on disk rather than in the context window: three markdown files, re-injected every turn by a hook, so the plan survives compaction, /clear and a crash. | task_plan.md, findings.md and progress.md (persistent) | ok |
| [PM Skills Marketplace](../../data/tools/phuryn__pm-skills.json) | Product-management frameworks packaged as skills and slash commands in nine plugins. Eight produce documents such as discovery plans, PRDs, OKRs and roadmaps; the ninth documents and audits an AI-written codebase before it ships. | discovery plans, PRDs, user stories, roadmaps and a shipping packet, as Markdown files in the workspace (persistent) | ok |
| [Spec Workflow MCP](../../data/tools/pimzino__spec-workflow-mcp.json) | Serves a spec workflow over MCP, with a dashboard showing approval state. | spec documents (persistent) | ok |
| [Spec Kitty](../../data/tools/spec-kitty__spec-kitty.json) | Spec-driven development with per-feature isolation via git worktrees. | spec plus worktree | ok |
