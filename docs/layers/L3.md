# L3: Memory

Decisions and state that survive individual turns or sessions. Compare persistence, retrieval, provenance and who can modify the stored state.

## Primary tools

| Tool | Purpose | Artifact | Verification |
|---|---|---|---|
| [MemoryOS](../../data/tools/bai-lab__memoryos.json) | Memory for agents arranged the way an operating system arranges storage: a hierarchy with separate storage, updating, retrieval and generation stages. Reachable over MCP. | hierarchical memory store (persistent) | ok |
| [Basic Memory](../../data/tools/basicmachines-co__basic-memory.json) | Keeps memory as Markdown files: human-readable, and diffable in git. | Markdown notes (persistent) | ok |
| [Beads](../../data/tools/gastownhall__beads.json) | Issue tracker for agents. Puts memory in structured data rather than conversation. | ticket database (persistent) | ok |
| [Graphiti](../../data/tools/getzep__graphiti.json) | Keeps memory as a temporal knowledge graph, so facts carry a validity period. | temporal knowledge graph (persistent) | ok |
| [Letta Code](../../data/tools/letta-ai__letta-code.json) | MemGPT lineage. Stateful agent harness whose agents rewrite their own memory, skills and prompts over time. Context is tracked in git through MemFS. | agent state (persistent) | check |
| [mem0](../../data/tools/mem0ai__mem0.json) | Long-term memory layer for agents. Handles extraction, storage and recall. | memory store (persistent) | ok |
| [MemPalace](../../data/tools/mempalace__mempalace.json) | Keeps conversation history verbatim rather than summarised, retrieves against it locally, and makes no API calls of its own. | verbatim conversation store (persistent) | ok |
| [MemOS](../../data/tools/memtensor__memos.json) | A memory layer with one API to add, retrieve, edit and delete, structured as a graph that a person can inspect and edit rather than an opaque embedding store. | inspectable memory graph (persistent) | ok |
| [Supermemory](../../data/tools/supermemoryai__supermemory.json) | A memory engine that extracts facts from conversations, keeps profiles, reconciles contradictions and expires what is stale, rather than storing everything and searching later. | extracted facts, profiles and context index (persistent) | ok |
| [Cognee](../../data/tools/topoteretes__cognee.json) | Ingests documents of any format and builds a self-hosted knowledge graph from them, so retrieval traverses relations instead of ranking chunks. | knowledge graph and vector index (persistent) | ok |
| [OpenViking](../../data/tools/volcengine__openviking.json) | Presents memories, resources and skills as one virtual filesystem under a viking:// protocol, so an agent browses its context with ls and find instead of querying an opaque index. Every retrieval leaves a trajectory. | context filesystem with three detail tiers (persistent) | ok |
