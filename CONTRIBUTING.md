# Corrections and suggestions

[Open an issue](https://github.com/mk668a/AIDD-compare/issues) to suggest a correction or a tool to compare.

For a correction, identify the tool and field, describe the proposed value, and link to the source that supports it. Include the relevant version or access date. For a new tool, explain which development task it supports and how it meets the [inclusion criteria](CRITERIA.md).

Useful evidence includes shipped files, implementation paths and project documentation. Separate a stated intention from an implemented feature. Include prerequisites and situations where the tool is a poor fit.

Proposals are reviewed against the published criteria and evidence. There is no aggregate score to optimize. Please report security vulnerabilities to the affected project's security contact rather than including exploit details in an issue here.
